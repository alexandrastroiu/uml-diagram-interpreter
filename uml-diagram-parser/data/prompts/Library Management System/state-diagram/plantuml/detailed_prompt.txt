Generate a UML State Diagram in PlantUML syntax for borrowing a book using a Library Management System.
After logging in, the user can browse the available books, see recommended books, search a specific book and apply filters.
The user can select a book, read book details and reviews.
The system waits for the user to select one or multiple books.
The user will wait for the system to approve the request.
If the request was approved, the user must return the book until the return date or apply online for a renewal.
If the book is not returned in time, the user will receive a fine.
If the request was not approved, the system will display a message and notify the user why the request was not valid. The user can make another request or end the session by logging out.
The user can cancel the membership at any time, but must return all the books.
